# 纸盒包装生成器方案书 V1.0（制造业服务平台集成版）

## 1. 项目目标

本项目的核心目标不是打造一个独立的 Pacdora 类设计平台，而是将“纸盒包装生成能力”作为一个功能模块，集成到现有的制造业服务平台中。

该平台已经具备以下业务基础：

* 中国工厂资源
* 中国供应商体系
* 韩国客户及未来海外客户
* 制造业服务与协作能力

纸盒包装生成器的定位是：

```text
作为制造业服务平台中的一个“包装设计 + 报价 + 生产协同工具”
```

用于打通以下业务链路：

```text
海外客户需求 → 包装设计 → 刀版生成 → 成本计算 → 工厂报价 → 生产执行
```

系统目标包括：

* 盒型参数化生成系统（服务报价与生产）
* FEFCO 标准盒型库（统一行业标准）
* SVG / PDF / DXF 刀版输出（直接用于生产）
* 包装材料成本计算（支持快速报价）
* 印刷、模切、粘盒等工艺报价
* 与供应商、工厂的协作流程打通
* 项目管理与订单管理集成

重点不是“设计体验”，而是：

```text
设计 → 报价 → 供应链 → 生产 → 交付
```

## 2. 项目背景

FEFCO 编码是国际纸箱包装行业常用的盒型分类体系，用四位数字表示不同纸箱结构。常见分类包括 0100、0200、0300、0400、0500、0600、0700、0900 等类型。

FEFCO 0201 是普通开槽箱（RSC），是瓦楞纸箱行业最常见的盒型之一。

传统包装刀版通常由设计师使用 Illustrator、AutoCAD、ArtiosCAD、Packmage 等软件绘制。

但在制造业服务场景中，更重要的是：

```text
快速响应客户需求 → 自动生成刀版 → 自动计算成本 → 快速报价 → 对接工厂生产
```

因此，本系统采用参数化生成方式：

```text
输入尺寸 → 自动生成刀版 → 自动计算面积 → 自动报价 → 进入生产流程
```

## 3. 系统核心逻辑

系统流程如下：

```text
客户选择盒型
    ↓
输入尺寸参数
    ↓
参数校验
    ↓
调用盒型算法
    ↓
生成几何坐标
    ↓
渲染 SVG 刀版
    ↓
导出 PDF / DXF（用于工厂）
    ↓
计算材料面积
    ↓
生成报价
    ↓
推送供应商 / 工厂
```

核心逻辑不是“画图”，而是：

```text
参数 → 几何 → 刀版 → 成本 → 报价 → 生产
```

## 4. FEFCO 分类与盒型库规划

### 4.1 FEFCO 主分类

| FEFCO 分类 | 中文名称        | 英文含义                            | 说明           |
| -------- | ----------- | ------------------------------- | ------------ |
| 0100     | 卷材、片材       | Rolls and sheets                | 原纸、瓦楞纸板、垫板   |
| 0200     | 开槽箱         | Slotted boxes                   | 普通纸箱、运输箱，最常用 |
| 0300     | 天地盖箱        | Telescope boxes                 | 上盖 + 下托结构    |
| 0400     | 折叠盒 / 邮寄盒   | Folder boxes and trays          | 飞机盒、电商包装     |
| 0500     | 抽屉盒 / 套筒盒   | Slide boxes                     | 抽拉式包装        |
| 0600     | 固定式箱        | Rigid-type boxes                | 工业重型纸箱       |
| 0700     | 预粘盒 / 自动成型盒 | Ready-glued boxes               | 彩盒、零售包装      |
| 0800     | 电商包装        | Retail and e-commerce packaging | 电商物流包装       |
| 0900     | 内衬 / 隔板     | Interior fitments               | 内托、隔板        |

### 4.2 第一阶段盒型策略（面向制造）

优先选择“高频 + 易报价 + 易生产”的盒型：

| 编码         | 盒型名称  | 优先级 |
| ---------- | ----- | --- |
| FEFCO 0201 | 普通纸箱  | P0  |
| FEFCO 0427 | 飞机盒   | P0  |
| FEFCO 0713 | 插舌盒   | P0  |
| FEFCO 0716 | 自动锁底盒 | P0  |
| FEFCO 0301 | 天地盖箱  | P1  |
| FEFCO 0501 | 套筒盒   | P1  |
| FEFCO 0502 | 抽屉盒   | P1  |
| FEFCO 0904 | 十字隔板  | P1  |

重点不是盒型数量，而是：

```text
每个盒型都能直接用于报价和生产
```

### 4.3 盒型算法设计原则

必须采用参数化模板，而不是静态文件。

错误方式：

```text
0201.svg
0427.svg
```

正确方式：

```text
BoxTemplateEngine
    ├── SlottedBoxEngine
    ├── MailerBoxEngine
    ├── TuckBoxEngine
    ├── AutoLockBottomEngine
```

示例：

```json
{
  "code": "0427",
  "name": "飞机盒",
  "inputs": ["length", "width", "height", "thickness"],
  "outputs": ["svg", "pdf", "dxf"]
}
```
