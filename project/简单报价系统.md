# 8. 简单报价系统详细需求

## 8.1 模块概述

简单报价系统是 MASS CONNECTED V1.0 的核心功能之一。

该模块的主要目标是让客户在不经过大量人工沟通的情况下，通过网站快速提交基础信息，并获得初步报价结果。

简单报价不是最终量产报价，而是用于帮助客户快速判断项目的大致成本范围。当客户需要正式量产、详细开发或复杂工艺确认时，应引导客户进入“详细报价”流程。

---

## 8.2 简单报价系统定位

简单报价系统的定位如下：

> 让客户快速了解项目的大致费用，并通过自动化方式生成初步报价书。

简单报价适用于：

* 客户初步了解项目成本
* 客户进行方案比较
* 客户尚未决定是否正式开发
* 客户只需要快速报价参考
* 平台希望减少初期人工沟通成本
* 平台希望通过报价功能吸引客户注册和使用

简单报价不适用于：

* 正式量产合同报价
* 高复杂度项目报价
* 需要供应商人工确认的报价
* 涉及特殊材料、特殊工艺、特殊认证的报价
* 需要工程师判断可行性的项目

---

## 8.3 简单报价与详细报价的关系

### 8.3.1 简单报价

简单报价用于快速估算。

特点：

* 输入信息较少
* 流程较快
* 可部分自动计算
* 可生成基础报价 PDF
* 结果仅作为参考
* 不直接作为最终交易价格

---

### 8.3.2 详细报价

详细报价用于正式项目推进。

特点：

* 需要更多技术资料
* 需要供应商参与
* 需要工程师确认
* 需要正式报价单
* 可进入合同、付款、生产流程
* 可作为订单执行依据

---

### 8.3.3 页面提示文案

在简单报价页面，应明确提示客户：

```text
当前报价为简单报价，仅供初步参考。
如需正式量产或进入项目执行阶段，请进入详细报价流程。
```

韩文页面可显示：

```text
간단 견적서입니다.
양산 진행 시 상세 견적에서 진행됩니다.
```

## 8.6 通用业务流程

简单报价的通用流程如下：

```text
用户登录
↓
进入简单报价分类
↓
选择报价类型
↓
上传资料或填写基础信息
↓
系统检查资料完整性
↓
用户选择材料、工艺、数量、交期等参数
↓
系统计算基础费用
↓
系统显示报价结果
↓
用户确认是否消耗积分
↓
生成 PDF 报价书
↓
报价记录保存到 MY PAGE
↓
用户可选择进入详细报价
```

## 8.8 积分消耗规则

简单报价系统应与积分系统联动。

| 功能         |        消耗积分 |
| ---------- | ----------: |
| 查看简单报价结果   |     0 或少量积分 |
| 生成 PDF 报价书 | 1,000 Point |
| 注塑模具报价计算   | 1,000 Point |
| 3D打印报价计算   | 1,000 Point |
| PCB开发报价计算  | 1,000 Point |
| 软件开发报价计算   | 1,000 Point |
| IC设计报价计算   | 1,000 Point |

```text
当前积分不足，无法生成报价书。
请充值积分或联系管理员。
```

可提供按钮：

* 充值积分

## 8.10 3D文件预览功能

PPT 中提出：

```text
STP파일을 넣으면 3D화면이 나온다.
```

即：

> 上传 STP 文件后，页面显示 3D 画面。

因此，注塑模具报价和 3D打印报价页面应支持 3D 文件预览。

---

### 8.10.1 V1.0 实现目标

V1.0 可以优先支持：

* STL 文件在线预览
* STEP / STP 文件上传保存
* 后台转换后预览
* 简单旋转、缩放、拖动查看
* 显示文件名称、尺寸、体积、估算重量

---

### 8.10.2 V1.0 可降低难度方案

由于 STP / STEP 文件在线解析复杂，V1.0 可采用阶段性方案：

#### 方案 A：先支持 STL 预览

* 用户上传 STL
* 前端直接显示 3D模型
* 系统计算体积和包围盒尺寸
* 用于 3D打印报价

#### 方案 B：STP 文件仅上传，不预览

* 用户上传 STP
* 系统保存文件
* 页面显示“文件已上传”
* 后台或工程师后续确认

#### 方案 C：服务器转换

* 用户上传 STP
* 后端转换为 STL 或 glTF
* 前端显示转换后的模型
* 适合后续 V2.0 开发

## 8.11.4 自动计算逻辑

### 8.11.4.1 产品材料费用

计算逻辑：

```text
产品材料费用 = 产品重量(g) × 材料单价(元/g) × 材料损耗系数
```

---

### 8.11.4.2 注塑加工费用

计算逻辑：

```text
单件注塑加工费 = 注塑机小时费用 ÷ 每小时产能
```

其中：

```text
每小时产能 = 每小时 Shot 数 × 穴数
```

---

### 8.11.4.3 模具费用

模具费用可根据以下条件估算：

* 产品尺寸
* 产品复杂度
* 模具类型
* 穴数
* 是否滑块
* 是否热流道
* 是否透明件
* 是否高外观要求
* 是否需要特殊钢材

V1.0 可先使用基础等级估算：

| 模具等级  | 说明       |
| ----- | -------- |
| 简易模   | 低成本、小批量  |
| 标准模   | 常规量产     |
| 高精度模  | 外观件、高精度件 |
| 热流道模  | 高量产效率    |
| 滑块结构模 | 有倒扣结构    |

---

### 8.11.4.4 包装费用

包装费用可先使用默认值：

```text
包装费用 = 单件包装费用 × 数量
```

V1.0 可设置：

* 不需要包装
* 简易包装
* 彩盒包装
* 吸塑包装
* 定制包装

---

### 8.11.4.5 运输费用

PPT 中运输费用部分写为：

```text
운송비용 ??????????
```

说明运输费用规则尚未明确。

V1.0 建议先采用以下方式：

* 用户选择是否需要运输
* 系统提示“运输费用需人工确认”
* 或设置基础估算值
* 最终详细报价时重新确认运输费用

页面提示：

```text
运输费用受目的地、体积、重量、运输方式影响，当前仅为估算，最终费用以详细报价为准。
```

## 8.12.4 自动计算逻辑


### 8.12.4.4 加急费用

```text

```

## 8.13 PCB开发简单报价

## 8.13.1 功能说明

PCB开发简单报价用于客户提交 PCB 开发需求，平台根据 PCB 层数、尺寸、复杂度、是否需要 SMT、是否需要BOM采购等条件生成初步报价。

---

## 8.13.2 输入信息

用户需要填写：

| 字段         | 类型 | 说明                 |
| ---------- | -- | ------------------ |
| 项目名称       | 文本 | PCB项目名称            |
| PCB类型      | 下拉 | 单面 / 双面 / 多层       |
| 层数         | 下拉 | 1 / 2 / 4 / 6 / 8层 |
| PCB尺寸      | 数字 | 长 × 宽              |
| 数量         | 数字 | 打样或批量              |
| 是否需要原理图设计  | 单选 | 是 / 否              |
| 是否已有Gerber | 单选 | 是 / 否              |
| 是否需要SMT    | 单选 | 是 / 否              |
| 是否需要BOM采购  | 单选 | 是 / 否              |
| 是否需要功能测试   | 单选 | 是 / 否              |
| 目标交期       | 日期 | 希望完成时间             |

---

## 8.13.3 文件上传

用户可上传：

* Gerber文件
* 原理图
* BOM
* PCB图片
* 产品说明书
* 参考样品图片

---

## 8.13.4 报价逻辑

PCB开发报价可由以下部分组成：

```text
PCB开发费用 = 原理图设计费用 + PCB Layout费用 + 打样费用 + SMT费用 + BOM采购费用 + 测试费用
```

---

### 8.13.4.1 原理图设计费用

影响因素：

* 电路复杂度
* IC数量
* 电源部分复杂度
* 通信接口数量
* 是否有MCU
* 是否有无线模块
* 是否有高压电路
* 是否有认证要求

---

### 8.13.4.2 PCB Layout费用

影响因素：

* PCB层数
* 尺寸
* 走线复杂度
* 高速信号
* 电源电流
* 射频要求
* 安规间距

---

### 8.13.4.3 SMT费用

影响因素：

## 8.26 本章结论

简单报价系统是 MASS CONNECTED 平台的第一核心功能。

V1.0 阶段不应追求所有报价完全自动化，而应优先实现：

1. 用户可以选择报价类型
2. 用户可以上传资料
3. 用户可以填写基础信息
4. 系统可以根据预设参数生成初步报价
5. 系统可以生成 PDF 报价书
6. 报价记录可以保存到 MY PAGE
7. 管理员可以在后台查看和管理报价
8. 用户可以从简单报价进入详细报价

简单报价系统的成功关键不在于一开始就做到完全准确，而在于建立标准化流程，让客户可以快速提交需求、快速获得参考报价，并最终转化为详细报价和正式订单。
