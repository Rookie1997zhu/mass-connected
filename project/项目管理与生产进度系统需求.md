# 10. 项目管理与生产进度系统需求

## 10.1 模块概述

项目管理与生产进度系统是 MASS CONNECTED 平台的核心业务模块之一。

如果说“简单报价”和“详细报价”解决的是客户如何提交需求、如何获得报价的问题，那么“项目管理与生产进度系统”解决的是客户在付款并正式进入项目后，如何持续了解项目进展、平台如何管理执行流程、供应商如何更新进度、管理员如何把控项目状态的问题。

该模块的核心目标是：

> 让客户能够通过网站清楚看到项目当前进行到哪一步，减少电话沟通，提高项目透明度和客户信任度。

---

## 10.2 模块定位

项目管理与生产进度系统不是普通的订单列表，而是制造业项目执行过程中的可视化管理系统。

该系统需要覆盖以下业务场景：

* 开发项目管理
* 模具项目管理
* PCB / SMT 项目管理
* 软件开发项目管理
* 3D打印项目管理
* 样品制作项目管理
* 量产项目管理
* QC检查管理
* 包装管理
* 出货管理
* 售后与异常管理

---

## 10.3 项目来源

项目可以由以下方式生成：

### 10.3.1 详细报价转项目

客户确认详细报价并完成付款后，系统自动创建正式项目。

流程：

```text
详细报价完成
↓
客户确认报价
↓
生成合同
↓
客户付款
↓
管理员确认付款
↓
系统创建正式项目
↓
项目进入执行阶段
```

---

### 10.3.2 管理员手动创建项目

部分线下项目、老客户项目、特殊项目，可以由管理员在后台手动创建。

管理员需要填写：

* 客户信息
* 项目名称
* 产品名称
* 项目类型
* 项目金额
* 供应商信息
* 预计交期
* 项目负责人
* 初始状态

---

### 10.3.3 简单项目直接创建

对于小型项目，例如：

* 3D打印
* 简单样品
* 简单PCB
* 小批量采购

管理员可以允许从简单报价直接转项目，但默认建议经过详细报价确认。

---

## 10.4 项目编号规则

每个正式项目需要生成唯一项目编号。

建议格式：

```text
MC-PRJ-YYYYMMDD-0001
```

示例：

```text
MC-PRJ-20260703-0001
```

字段说明：

* MC = MASS CONNECTED
* PRJ = Project
* YYYYMMDD = 项目创建日期
* 0001 = 当日流水号

如项目来自详细报价，应保留关联关系：

```text
简单报价编号：MC-QT-20260703-0001
详细报价编号：MC-DQ-20260703-0001
正式项目编号：MC-PRJ-20260703-0001
```

---

## 10.5 项目类型

系统应支持多种项目类型。

| 项目类型        | 说明                    |
| ----------- | --------------------- |
| 一站式产品开发     | 从设计、开发、模具到量产整体推进      |
| 注塑模具项目      | 以模具设计、加工、试模为核心        |
| 3D打印项目      | 以样品制作和快速成型为核心         |
| PCB开发项目     | 原理图、PCB Layout、打样、SMT |
| 软件开发项目      | 网站、APP、后台、API、服务器等    |
| IC / 电子开发项目 | 控制板、MCU、LED PCB、IC方案等 |
| 零部件采购项目     | 电子零部件、电池等采购           |
| 加工项目        | CNC、喷涂、挤出等加工          |
| 测试项目        | 环境测试、Abnormal测试等      |
| 量产制造项目      | 正式生产、QC、包装、出货         |

---

## 10.6 项目总状态

项目需要有统一总状态，方便客户快速理解。

建议项目总状态如下：

| 状态     | 中文说明              |
| ------ | ----------------- |
| 待启动    | 已创建项目，但尚未正式开始     |
| 进行中    | 项目正在执行            |
| 等待客户确认 | 需要客户确认资料、样品、价格或方案 |
| 等待供应商  | 等待供应商处理或反馈        |
| 等待付款   | 需要客户付款后继续         |
| 暂停中    | 项目因某些原因暂停         |
| 异常处理中  | 出现质量、交期或技术异常      |
| 已完成    | 项目已完成             |
| 已取消    | 项目取消              |
| 售后中    | 项目完成后进入售后处理       |

---

## 10.7 项目阶段状态

除总状态外，每个项目还需要有具体阶段状态。

# 10.8 一站式产品开发项目流程

一站式产品开发适用于从想法到量产的完整项目。

## 10.8.1 阶段流程

```text
需求确认
↓
方案评估
↓
产品设计
↓
机构设计
↓
电子开发
↓
样品制作
↓
样品测试
↓
客户确认样品
↓
模具设计
↓
模具加工
↓
试模
↓
试产
↓
量产准备
↓
正式量产
↓
QC检查
↓
包装
↓
出货
↓
项目完成
```

---

## 10.8.2 阶段说明

| 阶段     | 说明                   |
| ------ | -------------------- |
| 需求确认   | 确认客户需求、功能、外观、数量、目标价格 |
| 方案评估   | 判断项目可行性、风险和开发方式      |
| 产品设计   | 外观、功能、用户体验设计         |
| 机构设计   | 结构、尺寸、装配、模具可行性设计     |
| 电子开发   | PCB、MCU、线路、电源等开发     |
| 样品制作   | 3D打印、手板、PCB样品等       |
| 样品测试   | 功能、结构、可靠性基础测试        |
| 客户确认样品 | 客户确认样品是否可以进入下一阶段     |
| 模具设计   | 模具结构设计               |
| 模具加工   | 模具生产制作               |
| 试模     | 第一次试模、修模、确认成型效果      |
| 试产     | 小批量试生产               |
| 量产准备   | 物料、工艺、QC标准、包装准备      |
| 正式量产   | 批量生产                 |
| QC检查   | 按标准进行检查              |
| 包装     | 内盒、外箱、标签等包装          |
| 出货     | 安排物流和出货              |
| 项目完成   | 项目正式结束               |

## 10.9.2 模具项目状态说明

| 状态         | 说明               |
| ---------- | ---------------- |
| 产品资料确认中    | 确认3D图、尺寸、材料、外观要求 |

| 模具加工中      | 模具正式加工           |
| 试模中        | 进行T0 / T1试模      |
| 修模中        | 根据试模结果修改模具       |
| 样品确认中      | 客户确认试模样品         |
| 模具完成       | 模具达到可量产状态        |
| 模具保管中      | 模具由平台或工厂保管       |

* 模具图片

# 10.14 项目进度可视化

* 项目名称
* 项目编号
* 当前状态
* 当前阶段
* 总进度百分比

# 10.16 供应商进度更新

供应商应能参与项目进度更新。

## 10.16.1 供应商可更新内容

供应商可以更新：

* 当前生产状态
* 预计完成日期
* 已完成数量
* 问题说明
* 图片
* 视频
* 测试报告
* 出货资料

---

## 10.16.2 供应商更新限制

供应商更新内容不应直接向客户展示，必须经过平台管理员审核后再对客户可见。

原因：

* 防止信息不准确
* 防止供应商直接接触客户
* 防止客户看到内部价格或敏感信息
* 确保对外信息统一

---

## 10.16.3 管理员审核后发布

流程：

```text
供应商提交进度
↓
管理员收到通知
↓
管理员审核内容
↓
管理员可修改文案
↓
管理员选择是否公开给客户
↓
客户 MY PAGE 更新进度
```

---

# 10.20 项目异常管理

项目执行过程中可能出现异常。

## 10.20.1 异常类型

| 异常类型 | 示例          |
| ---- | ----------- |
| 资料异常 | 文件缺失、图纸错误   |
| 技术异常 | 结构不可实现、电路问题 |
| 模具异常 | 试模不良、修模次数增加 |
| 物料异常 | 元件缺货、材料涨价   |
| 交期异常 | 供应商延期       |
| 品质异常 | 不良率过高       |
| 付款异常 | 客户未按期付款     |
| 物流异常 | 出货延迟、清关问题   |

---

## 10.20.2 异常处理流程

```text
发现异常
↓
管理员创建异常记录
↓
填写异常原因
↓
上传图片或报告
↓
判断是否对客户公开
↓
提出解决方案
↓
客户确认方案
↓
执行解决方案
↓
关闭异常
```

---

## 10.20.3 异常记录字段

| 字段     | 说明                  |
| ------ | ------------------- |
| 异常编号   | 系统生成                |
| 项目编号   | 关联项目                |
| 异常类型   | 技术 / 品质 / 交期等       |
| 严重等级   | 低 / 中 / 高           |
| 异常说明   | 详细内容                |
| 责任方    | 平台 / 供应商 / 客户 / 待确认 |
| 解决方案   | 处理方式                |
| 是否客户可见 | 是 / 否               |
| 状态     | 处理中 / 已解决 / 已关闭     |

# 10.27 本章结论

项目管理与生产进度系统是 MASS CONNECTED 平台区别于普通企业官网和普通报价网站的核心功能。

客户真正关心的不只是报价，而是：

1. 我的项目现在进行到哪里了
2. 什么时候能完成
3. 有没有问题
4. 需要我确认什么
5. 钱付了以后有没有人在推进
6. 工厂是否真的在生产
7. 出货前有没有检查
8. 出现问题后谁负责

因此，V1.0 必须优先实现项目状态可视化、阶段管理、时间轴、客户待办和管理员进度发布功能。

只要客户能够清楚看到项目进展，就能显著减少沟通成本，也能增强平台的信任感。
