# 注塑模具自动报价（AUTO QUOTATION）需求

> 本文档整理自客户提供的三张需求图（사출·금형 자동견적），并结合现有 `simplequote` 引擎给出实现范围与可行性。金额规则以 **RMB** 为基准，展示层支持币种换算。

---

## 1. 背景与目标

- 为注塑（射出）项目提供**自动估价**：一次性给出「模具费」+「量产单价」，供客户快速参考。
- 精度要求宽松：**约 80% 准确**即可，用于初步判断，后续再走详细报价。
- 客户操作**尽量简单**，减少人工沟通。
- 参考站点：`custompartnet.com/estimate/injection-molding`、`xometry.com`、`icomold.com`。

---

## 2. 币种与换算

- 计算规则与基础参数（模具费、单价表）以 **RMB** 为原始单位存储。
- `SimpleQuote` 增加/启用 `currency` 字段，注塑自动报价默认 `CNY(RMB)`。
- 新增汇率参数 `rmb_to_krw`（后台 `QuoteParam` 可维护），报价单可同时展示 **RMB 原值**与**换算后的 KRW**。
- 平台其他业务仍以 KRW 为准，本模块通过币种字段与汇率隔离，不影响既有金额存储。

---

## 3. 模具费计算（图1）

```
模具费 = ( 基本模具费[按材料] + 滑块数 × 滑块单价 + 精密度加价 ) × (1 + 利润率)
```

### 3.1 基本模具费表（可后台维护）

| 材料 | 基本模具费(RMB) |
|---|---|
| ABS 普通 | 15,000 |
| ABS+Gf（玻纤增强） | 20,000 |
| PC（Polycarbonate） | 20,000 |
| PA66 | 20,000 |
| PP | 15,000 |

> 材料列表可持续新增。

### 3.2 附加项

- **滑块（slider / side core）**：每个 +1,000 RMB。用于成型 undercut（倒扣）的核心机构。
- **精密度 ≤ 0.2mm**：+2,000 RMB。
- **利润率**：+20%（`× 1.20`）。

---

## 4. 产品个别单价计算（图2）

### 4.1 基本单价表（可后台维护）

| 材料 | 基本单价(RMB/kg) | 基本报价(1g 以下, RMB) |
|---|---|---|
| ABS 普通 | 11 | 0.14 |
| ABS+Gf | 13 | 0.16 |
| PC | 18 | 0.18 |
| PA66 | 22 | 0.20 |
| PP | 9 | 0.14 |

### 4.2 计算步骤

以 PC 5.8g 为例：

```
1. 材料费    = 单价/kg × (单件重量 × 损耗系数) ÷ 1000     18 × (5.8×2) ÷ 1000 = 0.2088
2. 基本合计  = 基本报价(1g以下) + 材料费                  0.18 + 0.2088       = 0.3888
3. 颜色加重  = 基本合计 × 颜色系数                         0.3888 × 1.10        = 0.42768
4. 包装费    = × (1 + 包装率 3%)                          0.42768 × 1.03       = 0.4405
5. 利润      = × (1 + 利润率 20%)                         0.4405 × 1.20        = 0.5286
             ≈ 0.53 RMB / 个
```

### 4.3 系数与规则

- **损耗系数**：单件耗材重量 = 单件重量 × 2（含流道/损耗，系数可后台维护）。
- **颜色系数**：透明 ×1.10、半透明 ×1.05、普通 ×1.00。
- **包装率**：塑料费用的 3%（`× 1.03`）。
- **利润率**：+20%（`× 1.20`）。
- **MOQ 规则**：未指定 PANTONE 颜色时，**起订量 MOQ = 25KG**。

## 5. FAMILY 模具（一模多件）— 建议方案（待确认）

FAMILY 指把多个不同形状的塑料零件放进**同一套模具**一起注塑。

- **多零件输入**：一个报价单可添加多个零件，每个零件独立填写材料、重量、颜色、数量、滑块数、精密度。
- **能否 FAMILY 判定**：同一套模具一次只能注一种料，故要求**所有零件材料相同**；材料不一致时提示「无法 FAMILY，请分开上传 / 分开报价」。
- **模具费（FAMILY）**：
  - 基本模具费按材料取 **一次**；
  - 滑块费 = 所有零件滑块数之和 × 滑块单价；
  - 精密度加价：任一零件 ≤0.2mm 则 +2,000（计一次）；
  - 型腔 = 零件数（或各件自定 N 腔）；
  - 最后 × (1 + 利润率)。
- **单价**：每个零件各自按第 4 节公式独立计算，报价单分行列出。

## 6. 报价单模板（图3）

抬头：`MASS CONNECTED 사출·금형견적 / AUTO QUOTATION`

- **基本信息**：报价编号 `MC-2026-xxx`、客户公司、负责人、作成日、材料重量(g)、文件名(.stp)。
- **右上汇总**：金形单价 / 制品单价。
- **区块 1 — 模具费**：射出原材料、模具种类、型腔 `1×N`、模具材质。
- **区块 2 — 制品单价 TOTAL**：每个单价、颜色、生产费用、包装、运输费用、VAT、总单价。
- **区块 3 — 计算基准明细书**：재료비 / 기본비용 / 생산비용 / 특수비용 / 포장비 / 운송비。
- **脚注**：
  - 未指定 PANTONE 时 MOQ 25KG；
  - 上述单价为参考，约 80% 精度；
  - 报价自作成日起 **有效期 2 周**；
  - 支持 FAMILY 报价。

> **生产费用 / 运输费用**：一期公式未定义，**默认留空，由管理员手动填写**（区块 3 的「생산비용/운송비」同处理）。

## 8. 二期范围

### 8.1 阶段 A — 上传 STP 自动算重量/尺寸（已完成）

客户上传 `.stp` / `.step` 后，系统用 OpenCASCADE（`cadquery-ocp`）解析几何，自动得到体积、包围盒尺寸，并按材料密度估算单件重量回填表单；**不保存原始 STP**（临时解析后即删）。客户确认/微调后复用一期公式出报价。

| 项 | 说明 |
|---|---|
| 接口 | `POST /api/member/simple-quotes/parse-stp`（`stpParse`） |
| 解析服务 | `backend/apps/simplequote/geometry.py` |
| 密度参数 | 后台 `QuoteParam`：`density_ABS/ABS_Gf/PC/PA66/PP`（g/cm³） |
| 限制 | 文件 ≤30MB，解析超时 20s；失败回退手动填写 |
| 错误码 | `STP_FILE_INVALID` / `STP_PARSE_FAILED` / `STP_PARSE_TIMEOUT` |
| 前端 | `SimpleQuoteView.vue` 注塑表单「上传 STP 自动识别」 |

仍须客户手动填写/确认：材料、颜色、滑块数、精密度、型腔等（STP 不含此类语义信息）。

详见 [注塑自动报价二期技术方案.md](注塑自动报价二期技术方案.md)。

### 8.2 阶段 B — 倒扣分析推断滑块（已完成）

- `geometry.py` 的 `analyze_undercut`：基于可见性(遮挡)判定——对 X/Y/Z 三主拔模轴，从各面外侧沿 ±轴 射线求交，若两向均被材料挡住则计为倒扣面；选倒扣面积最小的轴为主拔模轴；残余倒扣占比超阈值时按侧向法向聚类得滑块建议数 + 置信度。
- 随 `POST /parse-stp` 响应的 `geometry.undercut` 返回；前端回填 `part.slider_count`，标注"建议值·需人工确认"，不直接定终价。
- best-effort：分析异常/超时不阻断体积解析。

### 8.3 阶段 C — 材料推荐 / 图纸 OCR（已完成）

- **几何规则推荐**：`recommend_material_by_geometry` 按壁厚代理/尺寸段给低置信度材料建议，随 `geometry.material_suggestion` 返回，未选材料时前端预填。
- **图纸 OCR**：`POST /api/member/simple-quotes/parse-drawing`（`drawingParse`）→ `apps/simplequote/ocr.py` 用离线 Tesseract（`eng+kor+chi_sim`）+ PyMuPDF 光栅化，抽取材料/精密度/颜色作可编辑建议回填。
- 限制：图纸 ≤15MB；`tesseract` 不可用/失败返回 `OCR_UNAVAILABLE` / `DRAWING_PARSE_FAILED` / `DRAWING_PARSE_TIMEOUT` / `DRAWING_FILE_INVALID`，均回退手动填写。
- 基于历史成交数据的材料训练模型待数据积累后迭代。

### 8.4 其它二期项（待做）

1. **条件自动分离 / 范用条件识别**：用 AI 识别客户输入中「我们的条件 + 范用条件」并自动归类（图1 提及）。
2. **FAMILY 智能判定**：根据上传文件自动判断能否 FAMILY，并给出分件建议。
3. **3D 在线预览**：STP 转 glTF/STL 后在页面旋转查看（与阶段 A 几何解析独立，见 `简单报价系统.md` 8.10）。

## 9. 可行性与改造点

现有 `simplequote` 已具备「参数驱动 + JSON 输入/结果 + PDF + 转详细报价」的完整骨架，**架构可直接承载**，主要为算法重写与参数扩充。

| 模块 | 现状 | 改造 | 可行性 |
|---|---|---|---|
| 参数 `QuoteParam` | `quote_type+param_key+value`，后台可维护 | 新增材料/滑块/精密度/颜色/汇率等参数 | 高，无需改模型 |
| 引擎 `calc_injection` | 材料费+加工费+模具档位 | 按新公式重写 | 高 |
| 输入 `SimpleQuote.inputs` | JSON 自由字段 | 增补新字段 + FAMILY 多零件数组 | 高，无需改模型 |
| 币种 `SimpleQuote.currency` | 已有，默认 KRW | 支持 RMB + 汇率换算展示 | 高 |
| 前端表单 | 已有注塑表单 | 增补字段 + FAMILY 录入 + 校验 | 中 |
| PDF 报价书 | 已有对比 PDF | 新做图3 韩语模板 | 中 |
| 后台参数页 `QuoteParamsView` | 已存在 | 录入新参数 | 高 |

**结论**：一期「算法 + PDF + 参数化」与二期阶段 A/B/C（STP 几何解析回填重量、倒扣→滑块推断、几何规则材料推荐 + 图纸 OCR）均已落地，均无需改 `SimpleQuote` 模型结构（解析/识别结果走 API 响应与现有 `inputs` JSON，不落库）。
