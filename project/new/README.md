## 通用业务流程摘要

1. **开发报价**：在 Excel 检查清单中选择开发类型，自动生成报价单，转为 PDF 发送至 lee@hellomisterlee.com
2. **付款**：开发费 300 万韩元以下需 100% 预付；300 万韩元以上可协商
3. **量产判定**：单次订单金额 500 万韩元以上视为量产；低于此金额按样品处理
4. **广告同意**：同意使用产品/PCB 照片可享开发费 10% 折扣
5. **运输**：样品多为航空到付；1kg 以下 24,000 韩元，2kg 以上按 重量 x 11,600 韩元
