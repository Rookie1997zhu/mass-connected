## 一、航空运输（到付）

**原文文件**：`01 항공 운송료/항공운송료 산정자료 260704.xlsx`

### 1.1 计费规则

| 步骤 | 规则 |
|------|------|
| 1 | 输入实重(kg)、长/宽/高(cm) |
| 2 | 体积重 = 长 × 宽 × 高 ÷ **6000** |
| 3 | 计费重量 = MAX(实重, 体积重) |
| 4 | 按计费重量查费率表自动匹配运费 |
| 5 | 费率表覆盖至 **50kg** |

**数据基础**：国际综合物流 INVOICE **19 件**（2026-03-31 ~ 2026-07-02 出港，广州→仁川 LCL，EXW）

### 2.2 海运运费（核心规则）

**计费 R/T（计费吨）** = MAX(实测 CBM, 重量 kg ÷ **250**)，按 **0.1** 向上取整

| 5 日服务 | **$50 / R/T** | $25 |

### 2.6 提货费参考

| 类型 | 费用 |
|------|------|
| 小箱 | ¥400 |
| 1 托盘 | ¥800 |
| 2~3 托盘 | ¥1,000 |
| 5 托盘 | ¥1,200 |

### 2.7 分析结论

| 发现 | 说明 |
|------|------|
| 计费方式 | 体积与重量（÷250）取大；如 721kg/1.18CBM 按 2.9 R/T 计费 |
| 4 日 vs 5 日 | 仅差 $5/R/T，国内附加费相同 |
| 固定成本 | D/O 19,000 韩元 + C/O ≈46,000 韩元/票，与小货无关 |
| 规模效应 | 货越大 R/T 单价越低；小货宜合并出运 |
| 误差 | 无观测的中间 CBM 区间可能有 ±10% 误差 |

## 五、系统开发需求

### 5.1 空运计算器

```
输入: 实重, 长, 宽, 高
体积重 = L×W×H / 6000
计费重 = max(实重, 体积重)
输出: 对应阶梯运费（韩元）
```

### 5.2 海运 LCL 计算器（双方案）

| 方案 | 触发条件 | 核心算法 |
|------|----------|----------|
| 国际综合物流 | 无电池 | R/T = ceil(max(CBM, kg/250), 0.1) |
| 海주物流 | 含电池 | CBM = max(最低CBM, 实测CBM) + 超重 kg 附加 |

### 5.3 可配置项

- USD/CNY/KRW 汇率
- 4 日/5 日服务选择
- 提货/C/O/托盘/韩国派送实费输入
- CBM 区间表后台维护

### 5.4 业务规则

- 单次订单 <500 万韩元：运输/JIG 等费用难单独精算，按样品逻辑处理
- 小批量合并出运可显著降低 R/T 或 BILL 固定费分摊
- 含电池货物 **必须** 走路由/资质不同的海주方案
