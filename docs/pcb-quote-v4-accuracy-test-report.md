## 2. 发布范围

报价优先级为 `exact_lookup` → `verified_estimate` → `manual_review`。FR-4 支持 2/4 层，FPC 支持 1/2 层，铝基板支持 1 层；验证边界为宽高 50~200mm、数量 5~200片。

客户价继续按以下规则计算：

```text
客户 CNY = JLC DOM 基准价 × 1.10
客户 KRW = 客户 CNY × 系统 CNY→KRW 汇率
```
