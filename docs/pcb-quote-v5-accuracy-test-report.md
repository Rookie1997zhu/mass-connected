## 4. 计价与降级验证

- 标准工艺缺省请求保持 v4 基准价不变，继续执行 `exact_lookup → verified_estimate → manual_review`。
- 客户价仍为 `JLC 基准/工艺调整价 × 1.10`，再按系统 CNY→KRW 汇率换算。
- FPC 0.12mm 和铝基板红色阻焊已在部署后计算中应用工艺调整，并返回工艺模型版本与调整明细。
- FR-4 红色等非标准工艺因材料门禁失败返回人工复核，制造费为 0。
- 2oz 铜厚、未列选项、材料不适用项和未验证组合均返回人工复核，制造费为 0。
