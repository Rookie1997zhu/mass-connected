# 管理端运行监控

图中的「资源占用」和「存储用量」可以做，但要按本项目的真实服务来，不能把不存在的 PDF 转换、定时调度、数据备份显示成正常。用户行为用现有业务表汇总，不另埋一套全站埋点。

数值说明要写在页面上：开发机读到的是 Docker 虚拟机或容器能看到的 CPU、内存和磁盘，不是云主机整机，也不是每个容器各自的占用。各服务的 CPU 曲线需要挂载 Docker 套接字，这一期不做。

## 目标与范围

做：

- 新页面挂在管理端「系统」组，仅 `super_admin` 可见。入口与三个区块：运行状态、存储用量、用户行为。
- 后台接口仅超级管理员可调用，不把这些数据放进现有公开的 `/api/health`。
- 运行状态：
  - 三张即时卡片：CPU（含 1 分钟负载）、内存（已用/总量）、磁盘（媒体目录所在盘）。
  - 服务健康与耗时：MySQL、Redis、聊天 WebSocket、切片任务、重任务、翻译任务。对象存储在 `USE_OSS=true` 时做一次桶探测，否则显示未启用。
  - 没有历史曲线时显示「暂无历史监控数据」，不画空图。
- 存储用量：
  - 本地媒体目录的总大小和文件数。开启 OSS 时再统计桶内对象总大小和数量。
  - 「重新统计」才全量扫描，结果缓存约 10 分钟，页面打开默认读缓存。
  - 孤儿文件只列出、不删除。24 小时内新出现的文件不算孤儿。名单分页，不在这一期提供删除按钮。
- 用户行为（近 7 天 / 30 天，来自现有表）：新注册会员、询价单、商城订单、询盘、博客文章浏览量合计、有登录记录的会员数。按天给出数量，不记录每个人的点击路径。
- 文案补管理端中文、英文、韩文。后端改完重启 `backend`；管理端页面需 `docker compose up -d --build admin`。

不做：

- 不挂载 Docker 套接字，不做各容器 CPU/内存对比图。
- 不把 PDF 转换、定时调度、数据备份显示为正常。当前 Compose 里没有这些独立服务，也没有 Celery Beat。
- 不自动删除孤儿文件，不在仪表盘替换现有业务数字卡片。
- 不新增全站埋点、热力图或第三方统计。

## 实现步骤

1. 后端增加仅超级管理员的三个读接口：运行状态、存储用量（含 `recount`）、用户行为（`days=7|30`）。运行状态用 `psutil` 读即时资源，数据库和 Redis 沿用现有健康检查并计时，三个 Celery worker 用短超时探测，聊天服务做一次连通检查。
2. 存储统计：本地走媒体目录；OSS 开启时分页列举对象。孤儿文件定义为存储里有、数据库文件字段未引用、且修改时间早于 24 小时的对象。扫描结果写入缓存，并返回完成时间。
3. 用户行为按天聚合 `User`、询价、订单、询盘和博客浏览量。没有按天明细的浏览量只给区间合计，不编造曲线。
4. 管理端新页面放在 [admin/src/layouts/AdminLayout.vue](admin/src/layouts/AdminLayout.vue) 的「系统」组，样式对齐现有后台卡片，不做成另一套监控皮肤。顶部写明开发环境与生产环境数值含义。
5. 构建管理端镜像并重启后端。用超级管理员打开该页；用运营账号确认菜单和接口都不可用。

## 建议后补（这一期不写进开发）

- 磁盘超过 85%，或数据库、Redis、任一任务进程失败时，给超级管理员发一条站内通知。不要每次刷新都发。
- 在运行状态里加三个任务队列的等待数量，比主机 CPU 更能说明报价和翻译是否堵住。
- 证书续期失败单独做一项。当前站点证书问题与容器 CPU 无关，但会影响前台是否打得开。
- 孤儿文件确认名单稳定后，再增加「仅超级管理员、二次确认」的删除。第一期只列出。
- 若以后要看 7 天 CPU 曲线，用定时任务每小时记一条，而不是为这一页引入 Prometheus。

## 风险与缓解

- 全量列举 OSS 或本地媒体会慢且可能产生列举费用：默认读缓存，只有「重新统计」才扫描。
- 容器内磁盘和内存不是宿主机整机：页面文案写明，避免把开发机数字当成云服务器容量。
- 孤儿判断漏掉某个文件字段会把仍在使用的文件标成孤儿：第一期只展示，删除留到核对之后。

## 验收标准

1. 超级管理员能看到 CPU、内存、磁盘三张即时卡片，以及 MySQL、Redis、聊天和三个任务进程的通断；对象存储未开启时显示未启用。
2. 页面不出现 PDF 转换、定时调度、数据备份的「正常」状态，也不出现各服务 CPU 对比曲线。
3. 存储区能显示总占用；重新统计后能看到完成时间；孤儿列表不提供删除。
4. 用户行为可切换 7 天和 30 天，数字来自注册、询价、订单、询盘和博客浏览，而不是空图。
5. 运营或销售打开该地址得到无权限；`npm run build`（admin）与管理端镜像构建成功。
