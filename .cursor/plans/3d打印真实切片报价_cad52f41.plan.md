# 3D 打印真实切片报价移植方案

## 目标与范围
- 在“简单报价”的 `print3d` 类型中支持 STL、STP/STEP 上传；STL 在浏览器即时预览，STP/STEP 复用 OCP 转 STL 后预览。
- 真实调用 PrusaSlicer 获取耗材重量与打印时间，再由 Django 按管理员配置统一计算 KRW 报价。
- 管理端可维护材料、打印机、质量/层高、填充率、后处理、电费、折旧、基础费、损耗、加价和加急参数，并能用样例值试算。
- 首版不支持 3MF/OBJ，不长期保存客户源模型，不整体并入参考 Flask 应用，也不沿用其“解析失败返回假数据”的逻辑。

## 实现步骤
1. **建立异步切片资源与迁移**
   - 在 [backend/apps/simplequote/models.py](backend/apps/simplequote/models.py) 新增归属于 `buyer` 的切片任务模型，记录文件、状态、阶段、输入参数、配置快照、切片结果、稳定错误码、过期时间；源文件仅供 Worker 使用并按清理策略删除。
   - 增加迁移、Serializer 和资源化接口：创建任务、查询本人任务状态；严格校验 `.stl/.stp/.step`、大小、文件特征和任务归属，未登录/越权不可访问。

2. **提取切片与 G-code 解析核心**
   - 从参考项目 [3D-Printing-Quote-Engine-master/3D-Printing-Quote-Engine-master/utils.py](3D-Printing-Quote-Engine-master/3D-Printing-Quote-Engine-master/utils.py) 提取 PrusaSlicer CLI 参数组装与 G-code 解析到 `backend/apps/simplequote/` 独立服务文件。
   - STEP 使用现有 [backend/apps/simplequote/geometry.py](backend/apps/simplequote/geometry.py) 的 OCP 能力转换/生成预览网格；切片读取真实 `filament used [g]` 和 `estimated printing time`。
   - 移除参考实现中的 3g、1h、PLA 密度等静默兜底；输出缺失、超时、模型越界或切片失败时任务明确失败，不生成报价。

3. **接入 Celery、Redis 与独立 Worker**
   - 增加 Celery 配置和切片任务，Redis 同时作为 broker/result backend；任务状态按“等待、STEP 转换、切片、完成、失败”更新，并限制超时、并发和临时目录。
   - 调整 [backend/Dockerfile](backend/Dockerfile) 为可复用构建阶段，PrusaSlicer/Xvfb 只进入切片 Worker 镜像；在 [docker-compose.yml](docker-compose.yml) 增加共享 media 卷的 `slicer-worker`，保持本地与生产 Compose 拓扑一致。
   - 固定 PrusaSlicer 版本与校验值，补充 MIT 版权声明及 PrusaSlicer AGPL 分发/源码提供说明；不移植 gmsh 进程内调用。

4. **迁移报价公式并保持兼容**
   - 扩展 [backend/apps/simplequote/calculator.py](backend/apps/simplequote/calculator.py)：以切片重量/时长为可信输入，支持“按克”和“成本累加”模式；成本累加包含材料、电费、折旧、基础/其他成本、打印机加价、后处理、数量和加急，并返回完整 breakdown。
   - 保留现有 `material_price_*`、`machine_hour_rate`、`post_*` 等参数作为兼容回退；新任务保存配置快照，避免管理员调价后历史报价漂移。
   - 将实时试算扩展到 `print3d`，但只有切片成功后的服务端重量/时长可生成正式报价，客户端不得自行伪造替换。

5. **把配置完整落到管理员端**
   - 继续复用 `QuoteParam` 存标量、`QuoteTable` 存材料/打印机/质量/后处理列表，补齐默认种子和后端校验。
   - 在 [admin/src/views/QuoteParamsView.vue](admin/src/views/QuoteParamsView.vue) 基础上增加专用 3D 打印配置页或分区表单，避免管理员手填内部 key/JSON；复用 [admin/src/api/index.js](admin/src/api/index.js) 请求层，补齐多语言、保存反馈和非法范围提示。
   - 管理员可启停选项、调整价格与工艺参数，并用重量/时长样例查看费用明细；接口继续使用 `IsAdminRole`。

6. **会员端上传、预览与任务交互**
   - 将 [frontend/src/components/quote/StpViewer3d.vue](frontend/src/components/quote/StpViewer3d.vue) 泛化为可接受本地 STL 和服务端 STEP 预览网格的模型查看器，保留旋转、缩放、自适应和资源释放。
   - 重构 [frontend/src/views/quote/SimpleQuoteView.vue](frontend/src/views/quote/SimpleQuoteView.vue) 的 `print3d` 区域：文件上传、材料/打印机/质量/填充率/支撑/数量/后处理选择、切片阶段与错误展示、结果明细；通过 [frontend/src/api/index.js](frontend/src/api/index.js) 创建任务并轮询，完成后自动回填只读重量和时长。
   - STL 选择后本地即时预览；STP/STEP 调用现有安全解析链获得预览。所有用户可见文案补齐中/韩/英/日 i18n。

7. **测试、部署与验收**
   - 后端补 G-code fixture 解析、两种公式、配置回退/快照、文件校验、任务归属、状态机、失败不报价及 Celery mock 测试；迁移执行前进与回滚检查。
   - 前端与管理端执行 lint/build；Docker 构建并用固定 STL、STEP 样件做真实切片冒烟，核对耗材/时长与参考引擎结果，检查 Worker 超时、失败重试、临时文件清理和服务健康。

## 风险与缓解
- **耗时与资源**：切片可能数分钟且高 CPU；用独立 Worker、并发限制、任务超时和状态轮询隔离 Web 服务。
- **报价精度**：结果依赖 PrusaSlicer 版本和 profile；固定版本、保存配置快照，并用基准模型建立回归值。
- **许可证**：参考项目代码为 MIT，PrusaSlicer 为 AGPL；隔离 Worker 不免除镜像分发义务，发布物需包含对应声明与源码获取方式。
- **客户模型隐私**：文件只在任务期暂存，按过期策略清理；接口按 `buyer` 归属隔离，不暴露公共 media URL。
- **兼容性**：旧报价仍可展示；旧参数键保留回退，新配置仅影响新切片任务。

## 验收标准
1. 合法 STL、STP/STEP 可上传并显示可旋转/缩放预览；非法格式、伪造文件和超限文件返回统一错误码。
2. 创建切片任务立即返回任务 ID，页面能显示阶段；Web 请求不等待 PrusaSlicer 完成。
3. 固定样件的耗材重量与时长来自 G-code，解析失败时明确失败且绝不使用假数据报价。
4. 管理员修改材料价、机时成本、层高、填充率或加价系数后，新任务结果按新值变化；历史任务配置快照与报价不漂移。
5. 普通会员只能读取自己的任务，管理员配置接口仅管理员角色可写。
6. 两种计价模式 breakdown 可复算，总价与数量、后处理、加急规则一致。
7. Django 检查与测试、前端/admin lint/build、Compose Worker 真实切片冒烟全部通过；失败任务不遗留超期源文件。
