# PCB 估算系数采样计划

## 目标与范围

目标：在现有精确查表价基础上，新增一套“大概报价”模型，用控制变量采样推导板材、层数、尺寸、数量的估算系数。

做：
- 复用 `scripts/jlc-cn-browser-sample.mjs` 的公开页面采样能力。
- 新增控制变量样本集，固定其他参数，只改变一个变量。
- 生成原始 JSON，例如 `scripts/jlc-cn-estimator-samples.json`。
- 生成估算系数文档/表格，补充到 `docs/jlc-pcb-price-list.md`。
- 明确标注该模型是“采样拟合估算价”，不是 JLC 官方公式。

不做：
- 不登录、不上传 Gerber、不下单。
- 不绕过验证码、风控、隐藏接口。
- 不承诺精确还原 JLC 官方计价算法。
- 不把板材价、层数价、尺寸价、数量价当作可绝对相加的官方单价。

## 采样设计

### 1. 基准样本

选择一个统一基准：
- 材料：FR-4
- 层数：2 层
- 尺寸：100 x 100mm
- 数量：5pcs
- 默认工艺：沿用现有公开报价采样口径

基准价作为所有差异计算的参考：

```text
basePrice = quote(FR-4, 2L, 100x100mm, 5pcs)
```

### 2. 板材变量采样

固定：2 层 / 100 x 100mm / 5pcs。

变化：
- FR-4
- FPC 软板
- 铝基板
- 铜基板
- 罗杰斯高频板
- 铁氟龙高频板
- HDI 盲埋孔板（若仍无法公开报价，则记录人工复核）

输出：

```text
materialDelta = quote(material, fixedLayer, fixedSize, fixedQty) - basePrice
materialRatio = quote(material, fixedLayer, fixedSize, fixedQty) / basePrice
```

### 3. 层数变量采样

固定：FR-4 / 50 x 50mm / 5pcs。

变化：
- 1 层
- 2 层
- 4 层
- 6 层
- 8 层

输出：

```text
layerDelta = quote(layer) - quote(2L)
layerRatio = quote(layer) / quote(2L)
```

说明：非 FR-4 的层数样本暂不扩展，避免材料型号差异过大。

### 4. 尺寸变量采样

固定：FR-4 / 2 层 / 5pcs。

变化：
- 50 x 50mm
- 100 x 100mm
- 100 x 150mm
- 150 x 150mm
- 200 x 200mm（如页面公开可报价）

输出：

```text
areaCm2 = widthMm * heightMm / 100
areaRateApprox = (quote(sizeB) - quote(sizeA)) / (areaB - areaA)
```

### 5. 数量变量采样

固定：FR-4 / 2 层 / 100 x 100mm。

变化：
- 5pcs
- 10pcs
- 20pcs
- 50pcs
- 100pcs
- 200pcs（如页面公开可报价）

输出：

```text
quantityDelta = quote(qty) - quote(5)
quantityRatio = quote(qty) / quote(5)
```

## 估算模型

生成两种模型，报价时优先级从高到低：

1. 精确查表：命中 `docs/jlc-pcb-price-list.md` 已有组合，直接用采样价。
2. 控制变量估算：未命中时，用拟合系数估算。
3. 人工复核：HDI、特殊工艺、超出采样范围过多、Gerber 相关项。

推荐公式：

```text
estimatedJlcPrice = max(
  minimumPrice(material, layers),
  basePrice
  * materialRatio
  * layerRatio
  * sizeRatio
  * quantityRatio
)

customerQuote = round(estimatedJlcPrice * 1.10, 2)
```

补充字段：

```json
{
  "pricingMethod": "estimated_by_sampling_model",
  "confidence": "low|medium|high",
  "requiresManualReview": false
}
```

## 风险与缓解

- JLC 有特价和最低消费，价格不线性：使用 `max(minimumPrice, estimatedPrice)`，并标注模型置信度。
- 非 FR-4 材料型号不明确：只做粗系数，未命中精确查表时建议中低置信度。
- HDI 页面结构特殊：默认人工复核。
- 采样价会随活动变化：记录采样时间，并建议定期重采样。
