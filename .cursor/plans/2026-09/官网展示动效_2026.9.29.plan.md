# 官网展示页动效（GSAP + Swiper）

沿用上次可行性结论：只加强展示页，制造业务文案和导航结构保持不变。不安装 Lenis、Lottie、PhotoSwipe、SplitType，不把顶栏改成透明或随滚动隐藏。

## 目标与范围

做：

- 首页：标题分段入场、副标题和按钮错开出现、区块滚入、工艺卡片悬停、案例横向滑动、新增博客条、底部转化区在手机上改为纵向。
- 博客列表与案例列表：桌面保持现有阅读布局，手机用 Swiper 横向滑动封面卡片。
- 页脚：补上博客入口，品牌区增加「发布询价」按钮；窄屏单列已经有，再把链接点击区域加大。
- `prefers-reduced-motion: reduce` 时关闭 GSAP 和 Swiper 自动播放，内容直接显示。

不做：

- 不把导航改成 ABOUT / SERVICE / WORK。
- 不把服务文案改成 Web Development、Branding 等创意公司条目。About 仍走现有内容页接口，不做 Strategy/Design 粘性分栏。
- 不在 [frontend/src/layouts/MainLayout.vue](frontend/src/layouts/MainLayout.vue) 上挂全局滚动劫持。询价、简单报价、商城、工作台、聊天不引入这些动画。
- 不改后端接口。

## 实现步骤

1. 依赖。在 [frontend/package.json](frontend/package.json) 增加 `gsap` 和 `swiper`。动画只在组件 `onMounted` 里创建，`onUnmounted` 里 `kill()` / `swiper.destroy()`，避免离开首页后 ScrollTrigger 还在监听。
2. 首页 [frontend/src/views/HomeView.vue](frontend/src/views/HomeView.vue)。
   - Hero：现有 `h1`、副标题、两个按钮用 GSAP 时间线。标题用 `clip-path` + `translateY` 自下而上展开（约 0ms），副标题约 300ms，按钮约 500ms。右侧蓝图面板做一次 clip 展开。不换现有询价/入驻链接。
   - 其下介绍、工艺、三步、角色、案例、资讯、新博客条：`ScrollTrigger` 在进入视口时淡入上移，`once: true`。
   - 工艺格 `.process-tile` 只加悬停位移和箭头移动，数据仍是 `fetchServiceCategories()`，链接仍是 `/rfq/new?category=`。
   - 首页案例三张改为 Swiper（`slidesPerView: 1.15` 手机、`3` 桌面，`grabCursor`，不自动播放）。无封面时保留现在的 CASE 占位。
   - 新增博客区块：`fetchBlogPosts({ page_size: 6 })`，Swiper 卡片链到 `/blog/:id`，标题旁链到 `/blog`。空列表不渲染该区。
3. 博客与案例页。
   - [frontend/src/views/BlogView.vue](frontend/src/views/BlogView.vue)：精选区在 `max-width: 960px` 时改为 Swiper；分类横滑和正文列表保持现状。
   - [frontend/src/views/CasesView.vue](frontend/src/views/CasesView.vue)：手机断点用 Swiper 替掉 `grid-3`，桌面仍为三列网格。
4. 转化按钮。首页底部 `.section-cta` 在 768px 以下改为标题、说明、按钮纵向全宽。Hero 两个按钮同样全宽、间距不小于 44px。不在全站加固定底栏，避免挡住工作台和聊天。
5. 页脚 [frontend/src/layouts/MainLayout.vue](frontend/src/layouts/MainLayout.vue)。现有四列在 1024px 两列、640px 单列。把博客从商城列拆出：商城只留商城；内容列放案例、资讯、博客（`/blog`，文案用已有 `nav.blog`）。品牌区在标语下加一个主按钮链到 `/rfq/new`（文案复用 `home.hero.ctaRfq`）。链接最小高度约 44px。
6. 文案。博客区块标题、空状态若不能复用 `blog.title` / `home.cases.viewAll`，补 [frontend/src/i18n/locales/{ko,zh,en,ja}.js](frontend/src/i18n/locales/zh.js) 的 `home.blog.*`。不新增创意公司口号。
7. 减弱动态。`window.matchMedia('(prefers-reduced-motion: reduce)')` 为真时不创建 timeline / ScrollTrigger，Swiper 设 `allowTouchMove: true` 但不要自动播放（本来也不自动播放）。
8. 按现有方式重建前台镜像：`docker compose up -d --build frontend`。桌面和约 390px 宽各看一遍首页、`/blog`、`/cases`。

## 风险与缓解

- ScrollTrigger 离开首页仍触发：只对 `.home` 内元素注册，卸载时逐个 `kill`。
- Swiper 样式污染全局：只在用到的页面引入 `swiper/css`。
- 案例没有封面：继续用现有占位块，不依赖灯箱。
- 包体积：只增加 gsap 与 swiper，不把 three 场景再绑进首页。
- 顶栏已经有 `backdrop-filter`，本次不再改滚动显隐，避免和验证条、工作台菜单抢空间。

## 验收标准

1. 首页标题、副标题、按钮按顺序出现；工艺卡片仍进入对应询价分类。
2. 首页案例可拖动滑动；有已发布博客时出现博客条，点击进入 `/blog/:id`。
3. 手机上博客精选和案例列表可横向滑动，桌面博客列表仍是现在的卡片流。
4. 手机上首页底部两个转化按钮纵向全宽；页脚有博客链接和「发布询价」。
5. 系统开启减少动态效果时，首页内容直接可见，无入场动画。
6. `/rfq/new`、`/simple-quote`、`/buyer` 页面不加载这套 ScrollTrigger。
7. ko / zh / en / ja 无缺失文案；`npm run build` 与前台镜像构建成功。
