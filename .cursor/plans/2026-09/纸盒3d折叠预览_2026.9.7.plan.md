# 纸盒生成器：3D 旋转与展开闭合预览

> 状态：**待实现**（方案已确认，未动代码）
> 日期：2026.9.7
> 关联：`.cursor/plans/纸盒刀版积分买断_2026.9.7.plan.md`（该方案第 2 节曾将 3D 列为「不做，暂缓」，本文档正式接续）

## 1. 背景

竞品在纸盒生成器里提供「牛皮纸纹理 3D 盒体 + 360° 旋转 + 展开/闭合滑杆」，展开态与刀版一致、闭合态为成品盒。我方生成器目前只有 2D 刀版 SVG 预览（`BoxPreviewPanel.vue`，含缩放/平移/尺寸标注）。

积分买断链路已上线，下载已收口到后端鉴权。3D 预览定位为**免费的转化前置体验**，不参与计费。

## 2. 目标与范围

### 做

- [ ] 前端新增折叠模型层：把公式引擎的隐式面板坐标显式化为「面板 + 折痕 + 折角」拓扑
- [ ] three.js 3D 预览组件：360° 轨道旋转、缩放、牛皮纸纹理材质
- [ ] 展开/闭合滑杆：`t ∈ [0,1]` 连续插值，`t=0` 全展开、`t=1` 完全闭合
- [ ] 覆盖全部 5 个内置引擎（锁扣类按近似交付，见第 5 节）
- [ ] `fixed_asset` 模板降级为「按外尺寸生成的通用盒示意」+ 明确免责文案
- [ ] 折叠自检断言：闭合态外尺寸与 `DielineGeometry.external` 一致
- [ ] 四语 i18n（zh/en/ja/ko）

### 不做（YAGNI）

- 不做水印与付费门槛：**3D 预览完全免费开放**，仅文件下载沿用现有积分买断校验
- 不做后端渲染、不做 3D 缩略图、不动任何后端代码
- 不做 3D 模型导出（GLB/OBJ/STEP）
- 不做用户印刷图案贴到盒面（自定义贴图）
- 不做从上传 SVG/DXF 自动推断折叠拓扑（CAD 级难题，`fixed_asset` 走通用盒示意）
- 不做展开动画的物理仿真（纸张弯曲、回弹）

## 3. 已确认决策

| 项 | 决策 | 备注 |
|---|---|---|
| 引擎覆盖 | **一次做全 5 个引擎** | 锁扣类允许近似 |
| 计费关系 | **3D 预览免费，不打水印**；只有下载收积分 | 3D 组件不依赖买断状态，少一层耦合 |
| `fixed_asset` | **显示通用盒示意** + 标注不代表实际刀版 | 同时兜住拓扑缺失时的降级 |
| 真值来源 | 折叠拓扑与 `build*Segments` **同源同公式** | 严禁两套几何真值 |
| 渲染技术 | 复用已有 three.js（`^0.185.1`）+ OrbitControls | 保持 dynamic import 独立 chunk |

## 4. 现状盘点与技术缺口

### 已具备

three.js 已在 `frontend/package.json` 依赖内（`three ^0.185.1`），且 `frontend/src/components/quote/StpViewer3d.vue` 已跑通完整套路：动态 `import('three')` + `OrbitControls`、灯光、`fitCamera` 相机自适应、`ResizeObserver`、卸载时 `dispose` 清理。**360° 旋转属于复用，不是新建。**

面板分界坐标在公式引擎里是显式变量（如 `build0201Segments` 中的 `xGlue / xL1 / xW1 / xL2 / xW2 / xEnd`、`yTop / yBodyTop / yBodyBot / yBot`，见 `frontend/src/lib/packaging/boxEngine.ts` 198–251 行），因此面板多边形可由同一批公式直接导出，**无需从线段反推轮廓**。

### 缺口

现有刀版产物只有无语义线段，没有「面」的概念：

```41:47:frontend/src/lib/packaging/types.ts
export interface LineSegment {
  x1: number
  y1: number
  x2: number
  y2: number
  kind: LineKind
}
```

3D 折叠需要的「面板多边形 + 折痕作为旋转轴 + 面板父子树 + 目标折角」这层数据当前为零，需按引擎补齐。

### 前置阻塞项

线上模板库当前状态（只读查询确认）：

```
count = 1
('01', 'slotted_rsc', 'fixed_asset', 0, True, True, True)
```

`formula` 模式模板数为 **0**。不先在后台配出至少一条 0201 公式模板，3D 折叠上线后无处可验（唯一模板会走通用盒示意分支）。此步无需写代码，但必须在 Step 1 之前完成。

## 5. 折叠模型契约（Step 1 产出）

新增 `frontend/src/lib/packaging/foldModel.ts`，建议契约：

```ts
export type PanelRole = 'body' | 'topFlap' | 'bottomFlap' | 'glueTab' | 'lock'

export interface FoldPanel {
  id: string
  parentId: string | null                 // null = 根面板
  polygon: Array<{ x: number; y: number }> // 2D 展开坐标(mm)，与 build*Segments 同坐标系
  hinge: { x1: number; y1: number; x2: number; y2: number } | null // 折痕轴，与父面板共享边
  targetAngleDeg: number                  // 闭合态相对父面板折角，通常 ±90 / 180
  role: PanelRole
}

export interface FoldModel {
  panels: FoldPanel[]
  rootId: string
  approximate: boolean  // true = 锁扣近似（mailer_folder / auto_lock_bottom）
}

export function buildFoldModel(geo: DielineGeometry, engineKey: EngineKey): FoldModel | null
```

`null` 返回值即降级信号（`fixed_asset` 或拓扑未实现），由 UI 切到通用盒示意。

### 各引擎拓扑清单与难度

| 引擎 | 面板数（估） | 折叠真实度 | 难度 |
|---|---|---|---|
| `slotted_rsc`(0201) | 4 侧板 + 8 摇盖 + 1 接舌 ≈ 13 | 真实 | 低 |
| `tuck_end`(0713) | 4 侧板 + 插舌 + 防尘翼 ≈ 15 | 真实 | 低 |
| `folding_shipping` | 底 + 4 侧 + 盖 + 翼 ≈ 12 | 真实 | 中 |
| `mailer_folder`(0427) | 含圆弧锁扣 | **近似**（锁扣不真实互锁） | 中高 |
| `auto_lock_bottom`(0716) | 四片互锁底 | **近似**（闭合态物理互相穿插，允许轻微穿模） | 高 |

锁扣近似必须在 UI 标注「折叠动画为示意」并写入验收标准，否则测试阶段会被当作缺陷反复返工。

## 6. 实现步骤（依赖顺序）

0. **前置（无代码）**：后台配出至少一条 `formula` 模式 0201 模板，确认生成器可正常出刀版。
1. **折叠模型层**：新增 `foldModel.ts` + 各引擎拓扑实现，由 `DielineGeometry` 派生，与 `build*Segments` 复用同一批公式变量。
2. **3D 组件（先只跑 0201）**：新增 `frontend/src/components/packaging/BoxViewer3d.vue`。要点：
   - 每个面板一个嵌套 `THREE.Group`，Group 原点置于折痕轴，父级旋转自动带动子级
   - 面板几何用 `THREE.Shape` + `ShapeGeometry`（兼容 0427 圆弧非矩形面板），`side: DoubleSide`
   - `t` 变化只改 Group 旋转，不重建几何
   - 复用 `StpViewer3d.vue` 的 renderer/controls/resize/dispose 结构
3. **材质与纹理**：可平铺牛皮纸贴图放 `frontend/public/textures/`；`SRGBColorSpace`、`anisotropy`、`repeat` 按 mm→贴图物理尺寸换算，UV 用平面投影保证跨面板纹理连续。内白外牛皮双色列为可选增强（需背靠背双 mesh，间距 = thickness），首版可先单材质。
4. **UI 接入**：`BoxPreviewPanel.vue` 增加「2D 刀版 / 3D 预览」切换 + 展开滑杆；3D 组件 `defineAsyncComponent` 懒加载；四语 i18n 补 key（见第 7 节）。
5. **逐引擎扩展**：`tuck_end` → `folding_shipping` → `mailer_folder` → `auto_lock_bottom`，每个引擎补一份折叠断言（参照 `dielineAssertions.ts` 思路）。
6. **降级分支**：`buildFoldModel` 返回 `null` 时渲染 `BoxGeometry`（按 `external` 三维）+ 免责文案，滑杆禁用。

## 8. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 拓扑按引擎手写，5 个引擎工期线性叠加 | 工期不可压缩 | 按第 6 节顺序交付，0201 先可用 |
| 3D 与 2D 刀版几何漂移 | 3D 与下载的 DXF 不一致，产生客诉 | 拓扑从同一 `DielineGeometry` 派生 + 闭合断言纳入 CI |
| 锁扣物理互锁 | 闭合动画穿模 | 近似折叠 + 末段限位，UI 标注「示意」 |
| 瓦楞 3mm 厚度渲染 | 单层平面闭合时露缝 | 首版平面 + 边缘描线；厚度仅闭合态有感知 |
| three.js 体积（约 700 kB / gzip ~185 kB） | 首屏变重 | 必须 dynamic import，保持独立 chunk |
| 用户误以为自定义刀版也能折 | 预期落差 | 通用盒示意 + 免责文案；后台配置页提示仅公式模板支持 |
| 低端设备 / 无 WebGL | 白屏 | 面板数 <50，性能风险低；`pixelRatio ≤ 2`；WebGL 不可用时回落 2D 并提示 |
| 前置模板未配置 | 上线后无处可验 | Step 0 前置完成 |

## 9. 验收标准

1. 0201 输入 200×150×100 / 厚 3mm，3D 页可鼠标拖拽 360° 旋转、滚轮缩放；切页与组件卸载后 renderer 已 dispose，无 WebGL 上下文泄漏。
2. 滑杆 `t=0` 全展开时，面板位置与 2D 刀版一致（对应面板中心偏差 ≤0.5mm）。
3. 滑杆 `t=1` 完全闭合时，包围盒等于 `DielineGeometry.external` 三维（各轴偏差 ≤0.5mm），该断言对 `slotted_rsc` / `tuck_end` / `folding_shipping` 必须通过。
4. `mailer_folder` / `auto_lock_bottom` 闭合态外尺寸同样满足 ≤0.5mm，但**允许锁扣区域穿模**，且 UI 显示「折叠动画为示意」文案。
5. 修改 L/W/H/厚度后 3D 与 2D 同步刷新，无需刷新页面。
6. `fixed_asset` 模板：3D 页显示按外尺寸生成的通用盒 + 免责文案，展开滑杆禁用。
7. 3D 预览无任何付费/水印门槛；下载仍需买断（沿用现有校验，不得回归）。
8. 四语 i18n 齐全、无硬编码用户可见文案。
9. `BoxGeneratorView` 首屏 chunk 体积不因 three.js 增长（three 保持独立懒加载 chunk）。
