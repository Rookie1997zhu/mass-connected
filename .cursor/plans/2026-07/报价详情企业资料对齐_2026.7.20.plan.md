# 报价详情 · 供应商企业资料对齐 + AI 翻译

## 范围

- 仅改买家报价详情展示：[`frontend/src/components/QuoteDetailModal.vue`](frontend/src/components/QuoteDetailModal.vue)
- **不改**供应商企业资料编辑页、不新增翻译 API
- 复用已有：`TextTranslateBlock` + `context-type="quote"` + `context-id="detail.id"` + `role="member"`（对应 `/api/member/quotes/<id>/translate`）

## 1. 展示结构对齐

将 `supplierProfile` 区块按「基础名片 → 能力选填 → 工艺/标签」重组：

**始终优先展示（有值才显示行）：**
- 公司名称（旁附简称 `short_name`，有则显示）
- 所在地：仅 `城市 · 国家`（**不再拼接 `region`**）
- 简介 `intro`
- 主营产品 `main_products`
- 平台评分 `score`（有值才显示）

**能力选填（空则整行隐藏，禁止一律打「—」）：**
- 成立年份、员工规模、厂房面积、月产能、质量认证、设备概况

**有则显示：**
- 擅长工艺 `process_names`
- 标签 `tags`

下方「企业介绍资料」公开附件区块保持不变。

## 2. AI 翻译按钮

对每条**非空文本内容**在原文下方挂 `TextTranslateBlock`（与现有报价备注/付款条件相同用法）：

| 字段 | 翻译文本 |
|------|----------|
| 公司名称 | `company_name`（若有简称可拼一行） |
| 所在地 | `城市 · 国家` 拼接串 |
| 简介 / 主营产品 / 月产能 / 认证 / 设备 | 对应字段原文 |
| 员工规模 | 原文（兼容旧自由文本与区间值） |
| 工艺 / 标签 | `join` 后的展示串 |

**不挂翻译（无语义文本）：** 成立年份、厂房面积数字、平台评分。

实现要点：
- 仅当 `(text || '').trim()` 有内容时渲染 `TextTranslateBlock`（组件自身也有此门禁）
- `context-type="quote"`、`:context-id="detail.id"`、`role="member"`
- 列表类字段用 computed 或模板内 `join`，保证翻译请求与屏幕展示一致

## 3. 后端

不改 `PublicSupplierProfileSerializer`：继续返回现有字段即可；前端不展示 `region`。无迁移、无新权限。

## 4. 验收

1. 报价详情企业资料顺序与企业资料表单逻辑一致；空字段不出现「—」占位行。
2. 所在地不含单独「地区」。
3. 每条有文字的信息旁可点「翻译」，结果出现在原文下方；切换语言后可再译。
4. 数字类字段无翻译按钮；公开附件区块与报价附件/接受报价流程无回归。

2. 为各文本字段补 `TextTranslateBlock`
