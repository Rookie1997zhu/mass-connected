# 管理端铺满宽度

左右留白来自 [admin/src/style.css](admin/src/style.css) 里 Vite 脚手架留下的 `#app`：宽度锁在 1126px，并且 `margin: 0 auto` 居中。宽屏上整块后台（深色侧栏和右侧内容）都被缩在中间。

## 目标与范围

做：

- 把 `#app` 改为占满视口：`width: 100%`、`max-width: none`、`margin: 0`、`text-align: left`，去掉左右边框。
- 在 [admin/src/layouts/AdminLayout.vue](admin/src/layouts/AdminLayout.vue) 让 `.layout` 宽度 100%、最小高度 100vh。侧栏仍为 220px，右侧主区域吃掉剩余宽度。
- 主内容区保留 Element Plus `el-main` 现有的内边距，表格和表单不要贴死到顶栏边缘。
- 重建管理端镜像：`docker compose up -d --build admin`。

不做：

- 不改菜单分组、不改各业务页布局、不改登录页卡片宽度。
- 不重写 `style.css` 里其余 Vite 示例样式。

## 实现步骤

1. 只改 `#app` 规则，使后台根节点横向铺满。
2. `.layout` 设为 `width: 100%`。
3. 构建并重建 admin 镜像。桌面宽屏打开后台，确认侧栏贴左、顶栏和内容区贴右，中间不再有一整块居中留白。

## 验收标准

1. 浏览器宽度明显大于 1126px 时，深色侧栏贴在窗口左缘，顶栏贴在窗口右缘。
2. 询价单、商品等列表仍在主内容区内，左右仍有原来的内容内边距。
3. `npm run build`（admin）与管理端镜像构建成功。
